Core philosophy

Engineering Principles

A fun game still needs solid engineering underneath. These are the rules I build by.

⚙️
C++ firstGameplay logic in C++; Blueprints wire data and visuals.
📊
Data-driven designTuning lives in Data Assets and tables, never in magic numbers.
🎲
DeterminismSeeded randomness and replayable state, so bugs can be reproduced.
🧪
Verified, not assumedReference tests, tolerances and property tests before every commit.
⏱️
Frame budget60 fps as a requirement, measured with profiling rather than guesswork.
🌐
Server authorityClients send intent; the server validates it and replicates the result.
🧩
Separation of concernsRules engines stay independent of rendering and UI.
📝
Honest historySmall commits that explain why. AI assistance is credited, never hidden.
